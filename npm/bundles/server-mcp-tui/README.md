# @horon-ai/messenger-server-mcp-tui

Installs the horon-messenger HTTP API server, the MCP server and the terminal UI
together. The server and MCP binaries come from their packages; this package
carries the TUI launcher and pulls the TUI platform binary. After install
`horon-messenger-server`, `horon-messenger-mcp` and `horon-messenger-tui` are
all on the path.

```bash
npm install -g @horon-ai/messenger-server-mcp-tui
# or
bun add -g @horon-ai/messenger-server-mcp-tui
```
