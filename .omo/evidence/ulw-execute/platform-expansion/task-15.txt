DEFECT
crates/cli/tests/cli.rs::platform_provider_without_credentials_requires_auth ran `chats discord`
and expected error.code == "AUTH_REQUIRED", but the cli crate had no feature enabling the sdk
discord provider. Under default sdk features (mock only) discord is not registered, so the code
is NOT_REGISTERED and the test failed under `cargo test -p hyper-messenger-cli` (exit 101).
Passed only under `--all-features`. Pre-existing at HEAD.

FIX (scope: crates/cli/Cargo.toml, crates/cli/tests/cli.rs)
- Added [features] discord = ["hyper-messenger-sdk/discord"] to crates/cli/Cargo.toml.
- Gated the test with #[cfg(feature = "discord")] so it compiles in and asserts the real
  AUTH_REQUIRED behaviour only when discord is enabled (--all-features); under default features
  it is compiled out.
